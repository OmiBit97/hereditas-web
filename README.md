# Hereditas Web

Sitio web de Hereditas — Asesoría Histórica, Innovación y Digitalización Patrimonial.

## Tecnologías utilizadas
- HTML5 / CSS3 / JavaScript (ES Modules)
- Servidor local en Node.js (cero dependencias externas)
- Assets locales optimizados (imágenes, iconos vectoriales, tipografías woff2)

## Cómo ejecutar en local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/ApoloStudiocreativo/hereditas-web.git
   cd hereditas-web
   ```

2. Iniciar el servidor local:
   ```bash
   npm start
   ```

3. Abrir en el navegador:
   [http://localhost:3000](http://localhost:3000)
