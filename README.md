# Hereditas Web

Sitio web de Hereditas — Asesoría Histórica, Innovación y Digitalización Patrimonial.

## Estructura del proyecto
- `index.html`: Página principal con toda la estructura HTML, estilos CSS y animaciones.
- `assets/images/`: Imágenes, logotipos e iconos vectoriales SVG locales.
- `assets/fonts/`: Tipografías originales (`.woff2`).
- `assets/js/`: Módulos JavaScript locales (`.mjs`).
- `local-server.js` / `start.bat`: Servidor HTTP local para desarrollo.

## Cómo ejecutar en local

Ejecutar en la terminal:
```bash
node local-server.js
```
O en Windows, hacer doble clic en `start.bat`.

Abrir en el navegador:
[http://localhost:3000](http://localhost:3000)
